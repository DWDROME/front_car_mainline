# 调参与验证手册

本文只保留当前可执行的参数、IPM、偏移检查和验证入口。更长的原始 SOP 和审计记录放在 `archive/source-notes/`。

## 最小验证命令

```bash
bash code/test.sh --host
bash code/test.sh
```

离线行为需要真实 `RAW_W x RAW_H` 图像序列，文档截图不能当 replay 输入。

常用审计：

```bash
bash tools/straight_baseline_audit.sh .diag/front_car_capture_live_current.png
bash tools/ipm_geometry_audit.sh .diag/ipm_recalib/ipm_raw_640x360.png
```

## 控制参数来源

控制参数只有一条来源链：

```text
code/core/config.hpp 默认值
-> 启动时 load_control_config(path) 读取外部配置覆盖
-> control.cpp 每帧通过 control_config() 取当前参数
-> solve_control_input_with_feedback(input, fb, ctrl)
-> drive_output_apply(ctrl)
```

配置路径：

```text
FRONT_CAR_CONFIG 非空：使用该路径
否则：/root/front_car_mainline.yaml
```

常用文件：

| 文件 | 用途 |
| --- | --- |
| `code/core/config.hpp` | 默认值 |
| `front_car_mainline.yaml` | 本地示例配置 |
| `/root/front_car_mainline.yaml` | 板端默认配置 |
| `code/core/config.cpp` | `key: value` 解析和支持字段 |

配置格式是扁平 `key: value`，支持 `#` 注释，不支持嵌套。未知 key 或非法值必须显式打印 `ConfigWarn`，不能静默吞掉。

## 参数分层

| 控制阶段 | 关键参数 | 说明 |
| --- | --- | --- |
| 目标速度 | `target_rps`, `element_target_rps`, `speed_target_rps` | 普通巡线、元素内速度和 FF 缩放参考。 |
| 视觉外环 | `outer_kp`, `outer_kd`, `outer_sign`, `straight_error_threshold`, `straight_turn_scale`, `max_target_yaw_rate` | `guide_error -> target_yaw`。 |
| yaw-rate 内环 | `imu_yaw_feedback_enabled`, `yaw_kp`, `yaw_ki`, `max_yaw_rate_correction`, `yaw_rate_filter_window` | IMU 有效时用 `target_yaw - yaw_now` 修正。 |
| 差速运动学 | `wheel_track_m`, `encoder_gear_diameter_m` | 把中心速度和 yaw 命令换成左右轮目标。 |
| 左右轮 FF + PI | `left/right_speed_base_percent`, `left/right_speed_kp`, `left/right_speed_ki`, `rps_filter_alpha`, `max_duty_percent` | 目标轮速到 duty；外设层仍有硬件占空上限。 |

硬边界：`pure_angle` 是参考版舵机角，不是当前差速 yaw-rate 目标。

## IPM 合同

当前生产 IPM 只有一个真相源：

```text
atg_reference/Project/CODE/shy_Image.c
  -> rot[3][3]
  -> inv_rot[3][3]
  -> Cal_rot_x() / Cal_rot_y()
  -> Cal_inv_rot_x() / Cal_inv_rot_y()
```

当前运行尺寸是 `160x120`。尺度合同：

```text
ROAD_WIDTH = 0.45m
pixel_per_meter = 116
IPM 赛道宽度约 52.2px
```

不要重新接回旧 `camera_param.c`、`mapx/mapy` 或运行时 `/root/ipm_matrix.txt` 作为生产路径。

## IPM 重标定流程

只有这些情况需要重标定：

- 中线远端系统性偏左/偏右。
- 相机被碰过或重新固定过。
- 换相机模组、镜头或第一次部署到新车。
- IPM 预览里直道明显弯曲。

从项目根目录按顺序执行：

```bash
bash tools/ipm_recalib_capture.sh
bash tools/ipm_recalib_generate.sh
bash tools/ipm_recalib_apply.sh .diag/ipm_recalib/ipm_matrix_tuned.txt
bash code/test.sh --host
bash code/test.sh
bash tools/ipm_geometry_audit.sh
```

验收看：

| 检查项 | 正常 |
| --- | --- |
| IPM 预览直道 | 左右边界近似竖直 |
| IPM 宽度 | 接近 `52px` |
| `control_ref` | x 接近 80，不系统性偏移 |
| 编译 | host 和 target 均通过 |

## 偏移检查

直道上最常用：

```bash
bash tools/ipm_recalib_capture.sh
bash tools/straight_baseline_audit.sh .diag/ipm_recalib/ipm_raw_640x360.png
```

看这些量：

| 报告键 | 正常范围 / 解释 |
| --- | --- |
| `guide_error` | 居中时接近 0，持续偏说明几何或控制方向有问题。 |
| `atg_rptsn_num` | 应有足够工作线点，过短说明选线不稳定。 |
| `atg_lpt0_found` / `atg_lpt1_found` | 角点命中情况。 |
| `control_ref` | x 坐标应接近 80。 |

方向判断：

- 车偏左：`guide_error` 应提示右转回中。
- 车偏右：`guide_error` 应提示左转回中。
- 如果方向反了，先查 `outer_sign`、编码器符号和电机映射。

## 已知修正点

| 项 | 当前事实 | 检查方式 |
| --- | --- | --- |
| IPM 中心 | 使用几何参考点，角度 bias 不再作为主要修正。 | 直道审计看 `control_ref` 和 `guide_error`。 |
| 编码器方向 | 左编码器取反，右编码器正向，控制层拿到前进为正。 | 前进时 `encoder_total` 应递增。 |
| 外环方向 | `outer_sign=-1.0` 是实车确认方向。 | `guide_error` 和车体补偿方向一致。 |
| IMU 零漂 | 启动采样 48 次估计 bias。 | `ImuReady` 日志 bias 应稳定。 |
| ATG 距离单位 | LS2K 编码器增量换算到 ATG `ENCODER_PER_METER=5800`。 | 圆环日志 `total_distence` 随实际行驶线性增长。 |
