# 全局地图：从源头算法到你的车

> 写给第一次接手这套工程的人。读完能在脑子里建立一张图：**这套代码到底是谁、跟谁、靠什么开车。**
>
> 这里只讲心智模型，不卷入具体数值和正在 debug 的疑点。
> 逐帧管道、字段名、各层合同看 `13_mainline_pipeline_map.md`；移植边界看 `atg_reference/PORTING.md`。

---

## 一句话

ATG2022 是一套**买来的"舵机车大脑"**（会找线、会认十字和圆环）。
我们把这个大脑搬进自己的**龙芯差速车**，用左右两个差速电机当手脚来开车。

> **大脑是舵机车的，手脚是差速车的——所有别扭都来自这里。**

---

## 一、三层身份

```text
①  ATG2022_Master V1.2          —— 买来的参考算法（源头，不在本仓库）
    平台：TC264 英飞凌单片机
    车型：舵机转向车
    开车方式：pure_angle（前轮转角）→ 舵机 PID → 打方向盘
        │
        │  原封不动复制算法源码（circle.c / cross.c / shy_Image.c …）
        │  规矩：贴近源码，移植逻辑不许藏在这一层
        ▼
②  atg_reference/               —— 参考算法在本仓库里的副本
    Project/CODE/   = ①复制来的算法，几乎不动（找线 / IPM / 十字 / 圆环）
    Project/USER/   = ①的主循环，只读参考，不编译进车
    port/           = 移植胶水层：喂图像和编码器，把 TC264 硬件换成龙芯
        │
        │  一座"薄桥"对接：code/tracking/atg_reference_mainline.cpp
        │  桥只把两样东西搬过来：选好的中线 rptsn ＋ 朝向误差 guide_error
        ▼
③  front_car_mainline           —— 你的车
    平台：龙芯 LS2K0300
    车型：差速车（靠左右轮转速差转向，没有舵机）
    开车方式：guide_error（朝向误差）→ target_yaw → yaw_cmd → 左右轮 duty
```

一句话串起来：①的大脑被搬进②，再通过③自己的差速手脚开车。

## 二、为什么会出问题：转向的"语言"不一样

源头车和你的车，描述"怎么转弯"用的根本不是一套单位：

| | ① ATG 源头（舵机车） | ③ 你的车（差速车） |
| --- | --- | --- |
| 怎么转向 | 舵机打一个角度 | 左右轮转速差 |
| 控制量 | `pure_angle`（前轮转角） | `guide_error`（朝向误差）→ `target_yaw`（目标角速度） |
| 执行 | servo PID → 舵机 PWM | yaw PI → 左右轮 duty |

源头在每个圆环阶段都用 `pure_angle` 算转向（IN / RUNNING / OUT 各一套 PID），执行器天生是舵机。

> **最容易犯的错**：图省事，把舵机车的 `pure_angle`（或饱和的 `Guide`）直接塞进差速车的控制环。
> 这就像拿"方向盘转 30 度"当成"左右轮差 30 转速"——单位根本不对，圆环里就疯狂打方向、跑飞。

**钉死的边界**（别再碰）：

- 薄桥只输出 heading 风格的 `guide_error`，由当前选线 `rptsn` 经 `atg_lookahead_error()` 算出，走差速车自己的链路。
- ATG 的 `pure_angle` / `Guide` 只当诊断和参考，**不进控制环**。
- `cross_type` / `circle_type` 只用来在元素里做减速 / 刹车，**不直接拿来转方向**。

## 三、一帧是怎么跑完的

```text
摄像头一帧灰度图（160 × 120）
   │
   ▼  ATG 算法（②的 Project/CODE，跑在③的龙芯上）
   ├─ image_handle       二值化、找左右边线
   ├─ find_corners       找角点
   ├─ IPM 逆透视          斜视图 → 俯视图（shy_Image.c 的 rot 矩阵）
   ├─ check_Half/circle  判断有没有进十字 / 圆环
   ├─ run_cross/circle   元素里按状态机补线、选线
   └─ 选线归一化           得到一条中线点列 rptsn
   │
   ▼  薄桥（atg_reference_mainline.cpp）
   ├─ copy_atg_midline       把 rptsn 抄进 rt->vision
   └─ atg_lookahead_error    按预瞄点算出朝向误差 guide_error
   │
   ▼  控制（③自己的 control.cpp）
   guide_error → target_yaw → yaw_cmd → 左右轮 target_l/r → duty
   │
   ▼
   左右两个电机（差速转向）
```

## 四、当前激活了什么

- 算法源码**全保留**：十字 / 半十字 / 圆环 / 回环 / Y 路 / 坡道 / 车库 / 道路分类都在。
- 当前比赛 profile **只激活**：十字、半十字、圆环。
- 回环、Y 路、坡道、车库：源码留着，但状态机里**每帧强制禁用**，不删、不触发。
- **目前没有停车线检测**（`stop_line` 恒为 0）：这是已知能力缺口，不是 bug——在移植出真正的检测器之前，车不会自动停。
