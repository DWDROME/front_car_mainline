# 当前主链与参考版对比

本文只记录当前 `port/atg2022-reference-control` 分支的运行合同，以及它和 ATG2022 参考版的边界。调参时优先相信当前代码、报告日志和实车证据。

## 两个源

| 源 | 角色 | 能做什么 | 不能做什么 |
| --- | --- | --- | --- |
| 当前分支代码 | 运行合同 | 定义当前一帧怎么跑、控制层消费什么、profile 启用什么。 | 不能被历史旧主线文档覆盖。 |
| ATG2022 参考版 | 算法来源和对照对象 | 提供搜线、角点、十字、圆环、补线、道路分类的参考顺序。 | 不能把舵机控制链直接照搬进差速车。 |

核心边界：ATG 是舵机车算法，当前车是差速车。参考版 `pure_angle -> servo_pid -> 舵机` 和当前 `guide_error -> target_yaw -> yaw_cmd -> 左右轮 duty` 不是同一类控制量。

## 当前一帧主链

```text
app/main.cpp
-> live / analyze / replay / offline
   -> device_capture_gray / device_load_gray
   -> drive_output_read_feedback(&fb)            # live 闭环路径
   -> encoder_total += 左右编码器增量均值
   -> tracking_process_frame(rt)
      -> atg_reference_process_frame(gray, encoder_total)
         -> image_handle()
         -> find_corners()
         -> 近线 track_type 切换
         -> check_Half() / check_circle()
         -> run_cross() / run_circle()
         -> round/ramp/yroad/garage 状态保持禁用
         -> 环岛补线拼接
         -> 选线归一化到 rptsn
         -> check_road()
      -> copy_atg_midline()
      -> atg_lookahead_error() -> rt->vision.guide_error
   -> control_input_t(line_found, guide_error, element_active, stop_line)
   -> solve_control_input_with_feedback()
   -> drive_output_apply()
   -> assistant / report / print 输出
```

主链只保留一条。不要新增 parallel pipeline、shadow pipeline 或靠 CLI/环境变量伪造元素状态。

## 层级合同

| 层 | 当前 owner | 合同 |
| --- | --- | --- |
| ATG 算法核心 | `atg_reference/Project/CODE/` | 保持贴近复制源码，负责搜线、IPM、角点、十字、半十字、圆环、补线、道路分类。 |
| ATG 移植层 | `atg_reference/port/reference_step.c` | 按当前 profile 调用 ATG；用 LS2K 编码器维护 ATG `total_distence` 距离合同；`ATG_ENABLE_*` 是元素启用边界。 |
| 当前视觉桥 | `code/tracking/atg_reference_mainline.cpp` | 薄桥，只把 `rptsn` 中线和 `guide_error` 写入 `rt->vision`，不恢复旧 `track/cross/ring` 字段。 |
| 控制层 | `code/core/control.cpp` | 只消费 `control_input_t`，链路是 `guide_error -> target_yaw -> yaw_cmd -> target_l/r -> duty`。 |
| runner | `code/app/runners.cpp` | 每帧由 ATG 结果生成 `control_input_t`；`line_found` 来自 `tracking_process_frame()` 返回值。 |
| report/assistant | `code/app/report.cpp`, `code/app/assistant.cpp` | 直读 ATG 当前帧全局变量输出诊断，不再显示旧主线字段。 |
| 外设 | `code/drivers/` | 保留 LS2K UVC、编码器、GPIO/PWM、电机映射和硬件占空上限。 |

## 当前启用的元素

| 元素 | 当前状态 | 说明 |
| --- | --- | --- |
| 十字 / 半十字 | 启用 | 由 ATG `cross.c` / `Half_check.c` 负责。 |
| 圆环 | 启用 | 由 ATG `circle.c` + `Patching_Line.c` 负责。 |
| 回环 / Y 路 / 坡道 / 车库 | 源码保留，profile 禁用 | 不删源码，但每帧保持不进入状态机。 |
| 停车线 | 未实现 | `stop_line` 恒为 0。 |

## 控制中线发布链

```text
ATG ipts0/ipts1
-> rpts0s/rpts1s
-> 元素状态机选线 / 环岛补线
-> rptsn
-> copy_atg_midline()
-> atg_lookahead_error()
-> guide_error
```

`guide_error` 是差速 yaw-rate 外环输入。不要把 ATG 舵机 `pure_angle -> servo_pid` 移植进这条链。

## 参考版对比要点

| 对照项 | ATG2022 / RT1064 参考版 | 当前分支 |
| --- | --- | --- |
| 基础视觉 | `image_handle()`、左右手追线、IPM、平滑、重采样、角点 | 使用 ATG 路线，生产 IPM 真相源是 `shy_Image.c::rot/inv_rot`。 |
| 元素状态 | `cross_type`、`circle_type`、`rptsn` 等全局变量 | 保留 ATG 原生状态，report/assistant 直读。 |
| 控制执行器 | 舵机车，`pure_angle -> servo_pid -> smotor` | 差速车，`guide_error -> target_yaw -> yaw_cmd -> target_l/r`。 |
| runtime 状态 | 参考版没有本项目旧 `runtime_t.track` | 当前 `runtime_t` 已收薄，不再翻译旧 `track/cross/ring/zebra`。 |
| IPM 来源 | ATG 函数或参考工程表 | 当前只允许 `shy_Image.c::rot/inv_rot` 做生产真相源。 |
