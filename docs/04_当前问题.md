## P0：圆环进不去左线追踪诊断

### 现象

- 偏右进左环时，中线笔直不向左弯，补线没有出现。
- 左侧圆弧清晰可见，但 `circle_type` 仍为 `NONE`。

### 当前判断

补线只在 `circle_type != CIRCLE_NONE` 后才执行。现在优先判断是 `check_circle()` 没触发，而不是补线本身坏了。

更具体的判断是 B 类根因：左边线没有覆盖到圆弧入口 L 角点。

```text
车偏右
-> 左边线 ipts0/rpts0s 追得短或起种子失败
-> find_corners() 扫不到左入口 L 点
-> Lpt0_found=false
-> check_circle() 不触发
-> circle_type=NONE
```

### 需要看的证据

抓偏右进左环的一帧日志，看：

| 日志 | 判定 | 下一步 |
| --- | --- | --- |
| 左 `seed=0` | B1：种子覆盖不到左边界 | 查 `seed_y_top`、`begin_x`。 |
| 左 `seed=1` 但 `raw` 左点数很小 | B2：爬线提前终止 | 查 `turn`、`block/clip`。 |
| 左种子落在圆环内圈黑块 | 种子认错目标 | 查起搜位置和方向。 |

已动过的方向：

- `conf` 阈值放宽到普通 Lpt `60~140 deg`。
- 入环 id 放宽到 `<35`。
- 爬线连续转向上限从 4 放宽到 6。

若这些版本下仍失败，优先怀疑未动项：

1. `seed_y_top=85`
2. `block_size=5` / `clip_value=8`
3. `begin_x=7`

### 下一步

1. 确认现场图是否来自上述阈值放宽之后的版本。
2. 抓一帧偏右进左环日志，区分 B1 / B2 / 种子认错。
3. 只根据日志改一个 owner 闸门，不复用上一帧、不造假角点、不加隐藏 fallback。

来源：[archive/source-notes/ATG圆环进不去左线追踪诊断.md](archive/source-notes/ATG圆环进不去左线追踪诊断.md)

## P1：drive32 外漂

### 现象

`drive32` 运行中存在外漂，已知疑点是 `IN` 积分累积和 `RUNNING` 后段 `guide` 升高。

### 当前判断

这不是文档层面能闭环的问题。需要实车日志把视觉误差、元素阶段、yaw 内环和左右轮反馈拆开看，避免只靠调大/调小一个参数压症状。

### 需要看的证据

- `circle_type` / `cross_type`
- `guide_error`
- `target_yaw` / `yaw_cmd`
- 左右轮目标和实际 rps
- IMU yaw-rate 是否启用、方向是否正确
- 元素内速度是否触发 `element_target_rps`

### 下一步

1. 先确认外漂发生在普通巡线、`CIRCLE_IN`、`CIRCLE_RUNNING` 还是 `OUT/END`。
2. 如果是 `IN` 积分累积，优先查 yaw PI 积分和元素状态切换时是否需要明确 reset。
3. 如果是 `RUNNING` 后段 `guide` 升高，优先查当前帧选线和补线点列，不先改控制器兜底。

## P1：半十字偏左

### 现象

进入 `CROSS_HALF` 后车明显向左偏。

### 当前判断

已存在 bounded relay 防止停死，但偏左根因仍需实车日志区分。

### 需要看的证据

- `far_rpts0s_num` / `far_rpts1s_num`
- `far_Lpt0_found` / `far_Lpt1_found`
- `track_type`
- `rptsn_num`
- `guide_error`

### 下一步

先判断是远线点数少、远线 L 点没命中，还是远线和 L 点都有但控制参数不合适。

来源：[archive/source-notes/14_偏移诊断与修正记录.md](archive/source-notes/14_偏移诊断与修正记录.md)

## 已知能力缺口

- 没有停车线检测，`stop_line` 恒为 0。
- IMU 方向仍需在启用强反馈前继续确认。
- 圆环距离门依赖 ATG 距离单位，编码器换算不准会影响进出时机。
