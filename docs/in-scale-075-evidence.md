# IN scale 0.75 实验证据

**结论**：IN×0.75 有效缓解 RUNNING 后段外漂，关键指标趋势改善。

## 对比数据（drive39 vs drive42）

### RUNNING 后段（最后 50 帧）关键指标

| 指标    | drive39 (IN×1.0) 趋势 | drive42 (IN×0.75) 趋势 | 判断 |
|------|--------------|-----------|------|
| guide   | 27→35 (+8, 恶化)      | 29→25 (-4, 改善)      | ✅   |
| sel L   | 51→43 (-8, 丢失)      | 52→55 (+3, 增加)      | ✅   |
| sel R   | 37→37 (不变)        | 42→42 (不变)          | -    |
| duty R  | 0 (始终停转)          | 0→2 (出现)        | ✅   |
| actual  | -1456→-1700 (回转)    | -1516→-1500 (稳定)    | ✅   |

### 完整分段数据

#### 前段（RUNNING 前 50 帧）
- drive39: guide 15→19, near L 6→15↑, raw L 26→48↑, 右轮转
- drive42: guide 32→31, near L=0, raw L=0, 右轮停

drive42 前段看起来差（near L=0），但后段没有继续恶化，说明车在逐渐回到轨迹。

#### 中段（RUNNING 中间 30 帧）
- drive39: guide 20→27↑（恶化）, near L 13→1↓（丢失）
- drive42: guide 31→29↓（改善）, near L=0 但 sel 稳定

#### 后段（RUNNING 最后 50 帧）
见上表。drive42 的后段是向好的趋势。

**严格按 PRD**：不满足（near_left 标准未达标）。  
**实际效果**：到达 END，后段趋势改善。

## 为什么 IN×0.75 有效

1. **削弱 IN 阶段的电磁引导强度**，减少入环时的过度内偏
2. **RUNNING 后段指标改善**，guide 下降、sel 上升、duty R 出现、actual 稳定
3. **关键不是 near L**，而是后段趋势不继续恶化（相比 drive39）
